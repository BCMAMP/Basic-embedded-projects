An automatic soil watering system. It utilizes a soil moisture sensor and an Arduino to maintain soil moisture levels, with an LCD display to show the readings captured by the sensor. (Note: The specific soil moisture variable value used in the program has not yet been tested in a real-world scenario.)

component :
1. Arduino
2. Servo
3. LCD 16x2 i2c
4. Soil Moisture Sensor
